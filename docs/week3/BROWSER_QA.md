# 第三週瀏覽器驗收

驗證日期：2026-11-11（Asia/Taipei）。本紀錄區分本機實際推論、受控錯誤測試與固定案例展示；雲端部署狀態另見部署驗收。

## 環境

- Chrome 有視窗模式，由快取的 Playwright CLI 0.1.24 建立隔離工作階段，不使用登入中的個人瀏覽器。
- 開發前端 `http://127.0.0.1:5173/`，`/api` 代理至本機 FastAPI `http://127.0.0.1:8000/`。
- 真實模型為 `week2-sequence-v1`，SHA-256 `aa3e984758796843bce68aa71fb06a4c84739a7d8048be475cc1bfe6855671ec`。QA 的本機 API 停用 Supabase 驗證，沒有將其稱為雲端驗收。
- 桌面 viewport 1440×1000；手機版為 390×844 viewport 模擬，沒有宣稱使用實體手機。可用頁面寬度包含捲軸差異。

## 實際操作與結果

| 情境 | 操作與觀察 |
|---|---|
| 即時歷程 | 以正常控制項新增兩球，輸入 FF、142 km/h、看球好球，再新增壞球。自動重建為 1 壞 1 好；真實 API 回應顯示已使用 2 球歷程。 |
| 清除舊結果 | 修改條件立即移除原有機率圖，不把舊對戰結果當作新對戰的分析。 |
| 競態 | 透過代理取得真實 1 壞球回應，延後送回；改為 2 壞球並先送回真實新回應。延遲舊回應到達後，所有可見球種百分比仍逐項等於 2 壞球 API 回應。沒有以假機率驗證。 |
| 503 錯誤 | 僅針對本機 `/predict` 受控回傳 503，顯示錯誤提示並移除舊機率圖；解除攔截後按重新連線，恢復真實推論。 |
| 真實等待上限 | 將本機推論請求保持未回應，約 20 秒出現喚醒說明；請求在 65 秒時中止並顯示超時。期間舊圖數量為 0，解除攔截後重試成功。不是修改時間的快速模擬。 |
| 啟動失敗後固定展示 | 阻擋全部 `/api/**` 後重新載入，確認啟動錯誤；仍可點固定示範案例，從網站靜態 JSON 成功載入及切換三個案例。進入固定模式後額外 API 請求數為 0。 |
| 固定模式唯讀 | 固定案例顯示「固定案例，非即時推論」、模型版本、截止日期與 SHA；投打、球數、出局、壘包、歷程欄位及新增／刪除皆唯讀。只能選預先計算案例。 |
| 模式退出 | 返回即時分析後重新載入球員、模型摘要與真實推論，控制項重新開放。 |
| 最終測試 | 讀取獨立 `/evaluation`，顯示全體 2025 球種覆蓋率 83.7%，並顯示凍結模型 log loss 1.400 不及投手收縮頻率 1.369。沒有把名目 90% 改成實測值。 |
| 不同評估範圍 | 切換網站可選投打子集，球種 log loss 變為 1.226，樣本數 69,044；全體則為 99,729。兩範圍分開揭露，沒有混用。比較任務按鈕可切換球種／落點／結果。 |
| 手機寬度 | 固定模式、歷程與評估表均可閱讀。390 viewport 下可用寬度為 375，頁面寬度同為 375，無整頁橫向溢出；長表格在內部容器橫捲。 |
| 完整離線包 | 另外載入正式編譯的 `http://127.0.0.1:8765/`。瀏覽器攔截全部外部 HTTP／HTTPS、保留 loopback；外部負向探測確實被阻擋。重新載入資產及實際本機 API 後，任意新增 FF、Z9、137.4 km/h、界外球，2 出局、三壘有人；核對實際 POST，球種機率由 68.6／16.2／8.6／6.0／0.5% 變為 33.4／28.3／23.2／12.6／2.2%。顯示本機模型快照，任意輸入可編輯；切固定模式則唯讀、額外 API 為 0。 |

錯誤測試的 503／網路中斷會產生預期的 console 網路錯誤；初次載入另見 favicon 404。這些不被記成「整個工作階段零錯誤」。

完整離線包的檢查使用瀏覽器層的外部 HTTP 阻擋，沒有關閉 Windows 實體網卡或啟用飛航模式。本機伺服器以關閉雲端驗證的離線方式啟動，相關啟停及解壓縮包驗證另由離線包紀錄提供。
