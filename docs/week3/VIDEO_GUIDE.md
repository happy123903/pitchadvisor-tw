## 實際錄製範圍

錄影使用 Chrome 有視窗模式，前端 `http://127.0.0.1:5173/` 經 `/api` 代理呼叫真正的本機 FastAPI `http://127.0.0.1:8000/`。使用 `week2-sequence-v1` 凍結模型，訓練截止 `2024-08-14`；一般推論沒有 mock 回應，也沒有重新訓練。

主要即時情境為 **德保拉對李凱威**，操作出局數、一壘狀態，加入四縫線 142 km/h、看球好球與曲球 125 km/h、壞球兩筆歷程，再查看機率、候選、樣本與預測集合。影片示範輸入與五分鐘現場講稿的投打範例可以不同，兩者皆使用真實模型。

第六段刻意攔截一次 `/api/predict` 並回傳 **503 模擬服務錯誤**，字幕與原始章節均明示模擬。其後切到唯讀固定案例，展示 `history-two` 與 `small-matchup`。這段不能當成正式雲端實際停機的證據。

最後一段將桌面 Chrome viewport 調為 **390 × 844 CSS pixels**，展示手機寬度，然後恢復桌面與即時模式。灰色區域是錄影畫布中未使用的部分，沒有裁成或冒稱實體手機錄影。
